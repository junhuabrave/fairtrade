# Local Copilot Skills

This folder is for storing local copies of "awesome copilot skills" or any Copilot skills materials you want to keep in the workspace but not commit.

Usage:
- Clone a repository into this folder (example):

```bash
git clone https://github.com/owner/awesome-copilot-skills.git tools/copilot-skills
```

- Or download/untar any archive into this folder.

This folder is gitignored by design so sensitive or large files can remain local.
